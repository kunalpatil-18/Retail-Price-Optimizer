# Retail Price Optimization Backend

This backend uses the EXISTING trained `demand_model.pkl`. It does not retrain the model.

## Setup

1. Create a virtual environment.
2. Install:
   pip install -r requirements.txt
3. Put the existing model here:
   models/demand_model.pkl
4. Run:
   python app.py

API:
- GET  http://127.0.0.1:5000/api/health
- POST http://127.0.0.1:5000/api/predict-demand
- POST http://127.0.0.1:5000/api/optimize-price

Example optimize request:

{
  "Product": "Gaming Laptop",
  "Category": "Electronics",
  "Region": "North",
  "StoreLocation": "Store 1",
  "CustomerType": "Regular",
  "Promotion": "No",
  "currentPrice": 10000,
  "BaseUnitPrice_INR": 10000,
  "UnitCost_INR": 7000,
  "Discount": 0.10,
  "objective": "Profit"
}

The response is generated by the trained model for every candidate price, then the best candidate is selected.
